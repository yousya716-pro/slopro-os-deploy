スロプロ自動取得プライバシーポリシー

プライバシーポリシー

対象アプリ：スロプロ自動取得
更新日：2026年10月15日

運営と適用範囲

本アプリは、運営者本人のスロプロ復帰OSの運用を補助します。このポリシーは、本アプリのGoogle OAuth連携とYouTube API経由で扱う情報に適用します。現在は初回連携・取得可否の検証段階で、会員情報の取得成功を保証するものではありません。

扱う情報

  • Googleが同意に基づいて発行するアクセス用・認証更新用トークンと、OAuthクライアント設定。
  • 指定した動画のID・タイトル・投稿者などの参照情報。
  • APIが本人に返すことを許可したコメントの本文・投稿者識別情報・投稿日時・返信関係など。本文取得が有効になった場合に限ります。
  • 取得確認日時、検証結果、保存の整合性を確認する記録。

Googleのログインパスワードは本アプリへ入力せず、Googleの正規認証画面でログインします。

利用目的と権限

YouTube読み取り権限を使い、本人が参照する機種情報の取得・更新確認・用途の検証を行います。APIから取得可能な情報だけを、本人の同意と利用権限の範囲で扱います。認証情報と取得本文は用途を分けて管理します。

保存とアクセス制限

認証更新用の情報は、専用の非公開GitHubリポジトリのActions secretへ暗号化して保存する構成です。短時間のアクセス用トークンは実行中のメモリで扱います。取得情報の保存を有効にした場合は、アクセスを制限した非公開リポジトリや保存先で管理します。認証情報・取得本文を公開サイトや一般公開のソースコードへ掲載しません。

Google、GitHub、および構成に応じたクラウド実行・保存サービスを、認証・処理・保存に必要な範囲で利用します。認証情報や取得情報へのアクセスは運営上必要な範囲に制限します。

第三者への提供とGoogle APIの利用方針

取得したGoogle・YouTubeデータを販売したり、広告配信や第三者向けのユーザー分析に利用したりしません。取得情報の閲覧は運営者本人による利用・検証の範囲で行います。

Google APIから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data PolicyのLimited Use要件に従います。YouTube APIの利用にはYouTube API Services Terms of Serviceも適用されます。

保持期間と削除

認証情報は、連携中の運用に必要な期間保持します。APIから取得した動画・コメント情報を長期保存する機能は、現時点では有効にしていません。保存機能を有効にする場合は、YouTubeの適用ポリシーに従う更新・保持・削除の条件を実装してから使用します。運用を停止した場合や削除を求めた場合は、関連するsecretと保存済みデータを運営者が確認し、必要な保存先から削除します。

Git履歴・バックアップなどには過去の記録が残る場合があります。保存先ごとの削除範囲を確認し、削除済みと報告する範囲を区別します。

Googleとの連携解除

Googleアカウントの接続管理から本アプリへのアクセスを取り消せます。連携解除後は、新たなGoogle APIアクセスを停止します。保存済みデータの削除も希望する場合は、サポート窓口へ連絡してください。

Google側の情報の取り扱いについては、Googleのプライバシーポリシーを確認できます。

この公開ページについて

この案内ページには、アクセス解析、広告、入力フォーム、Googleログイン処理を設置していません。GitHub Pagesで配信するため、閲覧時の通信情報はホスティング事業者により扱われます。

問い合わせと変更

連携・取得情報の削除・本ポリシーについては、Google認証画面に表示されるユーザーサポートメールへお問い合わせください。情報の扱いを変更する場合は、このページの内容と更新日を更新します。
